# 用户已确认的个人 IP：人物身份锁与生成边界

## 使用边界

本文件只服务于用户已经确认的个人 IP。它不是所有人物的通用模板，也不替代 `personal-ip-generator` 的授权、问答、风格选择和质量门槛。人物来源必须是用户本人提供或授权使用的照片、详细描述或已批准的 IP 图像。

不要把用户照片复制进 skill。不要从外貌推断民族、宗教、健康、性取向、政治等敏感属性。

## 已确认的可见身份锚点

- 长黑色卷发。
- 圆框眼镜。
- 黄色帽子。
- 亲切、活泼、可接近的脸部特征。
- 紫色斜挎包。

这些是角色身份和识别锚点，不是“温暖纸感手绘风”的通用要求。生成其他人物时不要强行套用它们。

## 已确认的角色视觉锁

- 轮廓：深棕色、有机、圆润、略带手绘不规则感。
- 材质：水彩、水粉、蜡笔和彩铅的手绘彩绘质感。
- 表面：细腻纸张颗粒、轻微干刷、哑光颜料。
- 色彩：暖米白底，黄色、珊瑚橙、紫色、青绿色等柔和暖色；避免荧光。
- 比例：圆润可爱的角色比例，但不幼儿化、不做成潮玩手办。
- 情绪：亲切、活泼、日常、略微搞怪或笨拙，但不丑化人物。
- 背景：暖米白或浅色纸张，简单、安静、留白充足。

## 场景变量

可以根据场景改变：

- 服装颜色、款式和季节感；
- 动作、姿势和表情；
- 道具和故事情境；
- 鞋子颜色与高帮/低帮结构。

统一鞋子规则：经典 Converse 风格帆布鞋的共同结构可以使用帆布鞋面、白色橡胶鞋头、白色橡胶鞋边、鞋带和简洁橡胶鞋底；不得出现可读品牌 Logo、文字或水印。只有在用户明确要求时才改变鞋子，编辑已有图片时必须写明“只修改鞋子，其他内容保持不变”。

## 角色生成工作流

涉及此人物时，先按 `personal-ip-generator` 执行：

1. 区分 `人物 IP` 与 `代表形象 IP`；真人相似度只来自授权身份源。
2. 将身份参考、风格参考和混合参考分开判断。
3. 把身份锚点、风格指纹、增强特征、配色、构图和负面约束写入 character lock。
4. 每个助手回合只问一个尚未确认的关键问题。
5. 在生成前展示完整 prompt lock 并取得用户批准。
6. 先生成一张包含六个候选的 3x2 预览，再让用户选择编号。
7. 候选选定后，才生成正式头像、3x3 表情板和可选透明贴纸。

## 人物提示词骨架

```text
使用 warm-paper-ip-style 的温暖纸感手绘风。
保留已授权人物的身份锚点：<脸型、发型、眼镜、帽子、包或其他可见锚点>。
使用水彩、水粉、蜡笔和彩铅质感，细腻纸张颗粒，轻微干刷，哑光颜料，深棕色有机圆润轮廓线。
使用暖米白背景、柔和暖光、低到中等饱和度的暖色体系。
本次场景：<服装、动作、表情、构图>。
固定：<不得改变的身份或画面元素>。
避免：3D 塑料潮玩、写实照片、荧光色、复杂背景、额外人物、畸形手脚、Logo、文字、水印。
```

## 人物质量门槛

- 脸型、发型、眼镜、帽子和紫色斜挎包在系列图中保持可识别。
- 变化来自表情和动作，而不是每次重新设计人物。
- 角色在小尺寸头像或贴纸中仍然读得懂。
- 不复制风格参考图中的人物、服装、姿势、道具、文字、Logo 或构图。
- 不将角色误做成 BJD、塑料潮玩、写实照片或平面矢量头像。
