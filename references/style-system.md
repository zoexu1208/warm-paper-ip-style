# 温暖纸感手绘风：跨媒介风格系统

## 一句话定义

一种有纸张触感、有手作痕迹、有生活气息的温暖角色视觉语言：人物圆润可爱但不幼稚，颜色柔和但有辨识度，动作和表情带着真实、调皮、略微笨拙的生命力；当它进入网页时，转译为温暖、清楚、留白充足的编辑式界面。

## 风格名称与气质

- 中文名称：温暖纸感手绘风；也可称“手绘编辑部风”或“生活化彩绘 IP 风”。
- 英文描述：warm tactile hand-painted character and editorial web style。
- 情绪关键词：亲切、活泼、松弛、有生命力、会玩、有人情味、轻微笨拙、温柔但不软弱。
- 反向关键词：塑料、炫技、冰冷、荧光、过度精致、机械、拥挤、戏剧化、商业模板感。

## 视觉指纹

### 线条

- 使用有机、圆润、略带不规则感的深棕色轮廓线。
- 线条可以有轻微粗细变化和手绘停顿，不要像几何矢量描边。
- 内部线条适量，用于头发、衣服褶皱、鞋子或表情细节；不要把画面变成密集线稿。
- 网页可把线条转译为手绘分隔线、箭头、批注和边框，但应集中使用。

### 形状与比例

- 角色以圆润、柔软、稳定的轮廓为主。
- 脸部亲和，五官清楚，眼睛和表情有足够识别度。
- 角色可以略微夸张，但不要变成幼儿化或潮玩手办比例。
- 网页形状使用轻微不规整的圆角、纸片边缘和柔和块面；避免全站统一的胶囊按钮和过度圆角卡片。

### 材质与渲染

- 水彩、水粉、蜡笔和彩铅的叠加质感。
- 细腻纸张颗粒、轻微干刷笔触、颗粒化的哑光颜料和柔和色彩过渡。
- 允许保留少量颜料不均匀和纸张纤维，让画面有手作温度。
- 禁止塑料高光、BJD、3D 潮玩、光滑渐变、金属反光和写实照片质感。

### 色彩

推荐的基础色板：

| 角色 | 色值 | 用途 |
|---|---|---|
| 暖米白纸张 | `#F6F0E5` | 页面和插画背景 |
| 深棕墨色 | `#2C2520` | 轮廓、主要文字 |
| 珊瑚橙 | `#D96F54` | 主强调、行动、情绪亮点 |
| 暖黄色 | `#E4A323` | 帽子、鞋子、阳光感细节 |
| 柔和紫色 | `#70568E` | 包、次级强调、个性配件 |
| 灰青绿色 | `#7B9F8F` | 辅助信息、平衡色 |

色彩规则：

- 以暖米白和深棕建立整体基调。
- 一张图或一个页面使用一个主要强调色，再配一到两个辅助色。
- 保持低到中等饱和度和柔和对比，不使用荧光色。
- 彩色应该像颜料落在纸上，而不是像屏幕上的高亮色块。

### 光线与背景

- 使用柔和、漫射、偏暖的光线。
- 避免锐利轮廓光、强烈戏剧阴影和电影海报式对比。
- 背景以暖米白、纸白或极浅的中性洗色为主。
- 留白服务于角色识别，不要用复杂场景抢走人物注意力。

### 构图

- 人物插画：角色清楚、留白充分、动作和表情可读。
- 头像或贴纸：脸和手势优先，缩小后仍能读懂情绪。
- 网页：把 Hero 当作一句视觉主张，文字、角色和行动入口有明确层级。
- 小批注、符号、编号只有在表达信息或引导阅读时才使用，不要把装饰当作内容。

## 跨媒介转译

### 人物与角色插画

- 优先保留脸型、发型、眼镜、帽子、标志配件等身份锚点。
- 服装、鞋子、动作和表情可以按场景变化，但材质、轮廓、比例和情绪不可漂移。
- 表情要有日常感和轻微夸张，例如用力、惊讶、撅嘴、吹泡泡、吐舌头；不要只做“漂亮头像”。
- 鞋子或服装可有明确风格参考，但不保留可读品牌 Logo、文字或水印。

### 个人网站与作品集

- 使用暖米白作为底色，深棕作为文字，珊瑚橙作为主要行动色。
- 用衬线标题承接纸张和编辑感，用清晰的无衬线正文保证阅读效率。
- 将手绘感集中在 Hero 插画、纸张区域、批注、线条和少量局部纹理上。
- 让 IP 角色承担“导览员”角色：引导访客理解网站，而不是作为孤立贴图。
- 卡片和按钮可以有柔和、不完全规则的边缘，但保持点击区域和层级清楚。
- 交互使用轻微位移、纸片翻动感或颜色变化；避免大量漂浮、弹跳和游戏化效果。
- 不要让纹理覆盖正文，不要用手写体替代所有界面文字，不要把每个区域装饰成贴纸。

### 内容卡片、社交图和展示板

- 先保证标题、主题和行动一眼可读，再加纸张、手绘线、颜料块或角色动作。
- 每张图设置一个主视觉重点和一个辅助情绪点。
- 使用暖色背景与一到两个彩色块建立系列感。
- 同一系列保持角色比例、轮廓线、标题位置和色彩层级一致。

## 允许变化与固定规则

允许变化：

- 服装、鞋子、动作、表情和局部配色；
- 页面布局和内容密度；
- 插画裁切方式和批注内容；
- 不同媒介中的纹理强度。

固定规则：

- 温暖、哑光、纸感的整体触觉；
- 有机圆润的线条与形状；
- 柔和但有辨识度的暖色体系；
- 亲切、活泼、真实的情绪；
- 清楚的主次关系和足够留白；
- 不使用塑料 3D、荧光、高光、复杂背景或模板化装饰。

## 风格验收

一个新产物满足以下大部分条件时，才可认为延续了该风格：

1. 去掉角色或插画后，网页仍保留温暖纸感和清楚的编辑气质。
2. 换成新的场景、服装或页面内容后，视觉 DNA 仍然成立。
3. 第一眼感受到的是亲切和生命力，而不是炫技和装饰堆叠。
4. 纸张和颜料质感可感知，但不会干扰文字和功能。
5. 人物身份锚点与视觉风格没有混淆。
6. 访客能够理解作品、主题和下一步行动。
